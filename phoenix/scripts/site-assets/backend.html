Get the Phoenix backend app

The private Phoenix dashboard as an app on your Windows computer or Android phone: users, usage, wellbeing trends, and a switch to pause Phoenix AI. Sign-in with your password and authenticator code is always needed.

Open it in the browser instead

Windows This device

Microsoft Edge or Google Chrome

  1. Press Install the app above, then Install in the box that appears.
  2. Or open the backend, then choose the install icon at the right of the address bar (a small screen with a down arrow), or ⋯ → Apps → Install this site as an app.
  3. Phoenix appears in your Start menu and taskbar with its own window.

Android This device

Chrome, Edge or Samsung Internet

  1. Open this page on your phone (use Copy the link and message it to yourself).
  2. Press Install the app, or open the browser menu ⋮ and choose Install app (sometimes called Add to Home screen).
  3. The Phoenix icon is added to your home screen and opens full screen.

Good to know

  1. It is the same backend as phoenix.neurohubcommunity.org/admin/, so there is nothing to keep up to date: it always shows the latest.
  2. Nothing is stored on the device. Anyone without the Admin role, password and authenticator code sees only the sign-in screen.
  3. On an iPhone, open this page in Safari, tap Share, then Add to Home Screen.
